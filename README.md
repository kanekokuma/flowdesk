# FlowDesk

企業内の申請・承認業務を電子化するWebアプリケーションです。
社員、部、課、役職をIDで管理し、導入企業向けに設定した承認ルールから、申請者の所属・申請種別・金額に該当する承認経路を適用します。

## 技術構成

- Python / Flask
- MySQL 8.0
- SQLAlchemy
- Docker Desktop / Docker Compose
- Kubernetes / Minikube
- OrbStack
- PatternFly 6.6.0
- Tabler Icons Webfont 3.44.0


初期データには社員、部、課、役職、申請種別のみを登録します。申請データ、承認履歴、通知は初期状態では登録しません。

## 起動方法

### Docker Composeで起動

```bash
./scripts/start-compose.sh
```

起動後、ブラウザで以下を開きます。

```text
http://localhost:5001
```

### Minikube / OrbStackで起動

Kubernetes上にデプロイする場合は、以下を実行します。

```bash
./scripts/start-k8s-local.sh
```

既存のMinikube環境が起動できない場合は、FlowDesk用のMinikube環境を削除して再構築します。Minikube内のデータは初期化されます。

```bash
./scripts/rebuild-k8s-local.sh
```

起動後、別のターミナルで `minikube service workflow-app -n workflow-app` を実行すると、Kubernetes Service経由のURLを確認できます。

詳しい手順は[k8s/README.md](k8s/README.md)を参照してください。

この構成では、FlaskアプリとMySQLをKubernetesのDeployment/Serviceとして起動します。

## 申請種別ごとの入力項目

| 申請種別 | 固有の入力項目 |
|---|---|
| 経費申請 | 金額、利用日、費目、支払方法、支払先、領収書提出状況、案件コード、税区分、費用負担部門 |
| 購買申請 | 金額、購入品名、数量、単価、購入先、希望納期、予算コード、見積書提出状況、購入先選定理由 |
| 勤怠申請 | 対象日、勤怠区分、開始時刻、終了時刻、振替日、勤務場所、緊急連絡事項 |
| 稟議申請 | 金額、稟議区分、稟議内容、背景・課題、費用内訳、期待効果、リスク・懸念点、関係部門、希望決裁日 |
| 交通費申請 | 金額、利用日、出発地、到着地、交通手段、往復区分、訪問先、業務目的、領収書提出状況 |
| 在宅勤務申請 | 対象日、在宅勤務日、在宅勤務区分、勤務場所、開始時刻、終了時刻、予定業務、通信環境、緊急連絡先 |

- 承認履歴
- アプリ内通知

- 申請一覧の検索・絞り込み
- 申請詳細での承認進捗表示
- 差し戻し申請の修正・再申請
